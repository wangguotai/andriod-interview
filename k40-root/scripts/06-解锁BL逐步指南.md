# Redmi K40 (alioth) — Bootloader 解锁逐步指南

> **适用前提（已核实你的设备）**：国行 CN / `ro.boot.hwc=CN` / `ro.miui.region=CN` /
> **MIUI 13（非 HyperOS）** → **无需小米社区授权、无需答题**，直接绑定即可。
> 账号必须也是国区。

---

## 总览：4 个阶段

| 阶段 | 耗时 | 在哪做 |
|---|---|---|
| A. 手机端前置准备 | 5 分钟 | 手机 |
| B. 绑定账号设备 → **开始计时** | 5 分钟 | 手机 |
| C. Mac 端运行解锁工具 | 10 分钟 | Mac |
| D. 等满 168 小时 → 真正解锁 | **等待 7 天** | Mac + 手机 |

**关键认知**：168 小时是**从「绑定账号和设备」成功那一刻开始算**，不是从运行工具开始。
所以**今天就把 B 阶段做完**，否则等待期一天天往后拖。

---

## 阶段 A · 手机端前置准备

### A1. 插卡（必须）

- 插入一张**能正常通话/短信的 SIM 卡**
- 国行设备必须用国区小米账号
- ⚠️ 不要用境外卡 + 国区账号混搭（会报 code 20045 区域不匹配）

### A2. 登录小米账号

- 设置 → 小米账号 → 登录
- **确认账号已绑定手机号**（否则报 code 20041）
  - 若没有：用此链接补绑 https://account.xiaomi.com/pass/serviceLogin?checkSafePhone=true

### A3. 开启「查找设备」（必须）

- 设置 → 小米账号 → **查找设备** → 打开

> 为什么必须：绑定和解锁流程都依赖它。若设备已被某账号通过「查找手机」锁定，
> 会报 code 20038，需先去 i.mi.com/mobile/find 关掉该锁定。

### A4. 关闭自定义 DNS（重要坑）

- 设置 → 连接与共享 → 私人 DNS → **关闭**
- 若装了 VPN/广告拦截类 App，**先关掉**

> 自定义 DNS 会导致小米服务器把设备判定为「未激活」，报 code 10013 且等待期变成 7 天重算。

### A5. 用移动数据激活一次

- **切到移动数据（非 WiFi）**
- 设置 → 小米账号 → 小米云服务 → 开启「通话记录」「短信」同步

> 这是官方推荐的激活方式，能让 SIM 在服务器侧标记为已激活，避免 code 10013。

---

## 阶段 B · 绑定账号与设备（★ 等待期从这里开始）

### B1. 开启开发者选项

设置 → 我的设备 → 全部参数 → 连点「**MIUI 版本**」**7 次** → 提示「您已处于开发者模式」

### B2. 打开 USB 调试

设置 → 更多设置 → 开发者选项 → **USB 调试** → 打开

### B3. 打开 OEM 解锁

设置 → 更多设置 → 开发者选项 → **OEM 解锁** → 打开

> 若此项**灰色不可点**：说明账号/网络条件未满足。回到 A1~A5 逐项检查，
> 通常是没有插卡、没开查找设备、或账号未绑手机号。

### B4. 绑定账号与设备 ★★★

设置 → 更多设置 → 开发者选项 → 「**设备解锁状态**」/「Mi Unlock status」
→ 点「**绑定账号和设备**」→（会弹窗）**同意**

**看到「绑定成功」/「已添加」即成功，168 小时倒计时从此刻开始。**

### B5. 等待期内的禁忌（违反会重新计时）

| 禁止操作 | 后果 |
|---|---|
| 退出小米账号 | 绑定失效，重新计时 |
| 关闭「查找设备」 | 绑定失效 |
| 恢复出厂设置 | 绑定失效 |
| 换 SIM 卡 / 长时间离线 | 激活状态失效，报 10013 |
| 换用另一个小米账号 | 不可解锁 |

### B6. 验证绑定是否真的生效

回电脑执行（手机保持正常开机 + USB 连接）：
```bash
bash scripts/01-check-device.sh
```
能看到 `BL 锁状态 : locked` 即正常，此刻先**不用管**，等满 7 天再进 C 阶段。

## 阶段 C · Mac 端运行解锁工具

> 我们的实测：小米官方解锁工具是 **Windows 独占**，Mac 上用 `miunlock`（已装好）。

### C1. 让手机进入 fastboot 模式

1. **手动关机**（不是重启）
2. 按住 **音量下 + 电源**，直到出现「**FASTBOOT**」字样（屏幕上是一只兔子/安卓图标）
3. 用 USB 线连接 Mac

> ⚠️ 必须是 **fastboot 模式，不是 fastbootd**。
> 确认：`fastboot devices` 能看到设备序列号。

### C2. 确认 Mac 认到设备

```bash
fastboot devices
# 期望输出: 57d05823	fastboot
```

若为空：
- 换 USB 线（**优先原装线**，劣质线是头号原因）
- 换 USB 口，**优先 USB-A 2.0**；必要时经 USB Hub
- 拔插一次

### C3. 运行解锁工具

```bash
cd /Volumes/ext/workspace/projects/android/interview/android-interview/k40-root
./.venv-miunlock/bin/miunlock
```

### C4. 按提示完成登录（重要，照做）

工具会依次：

1. **`Press Enter to open confirmation page`** → 按回车，浏览器自动打开小米登录页
2. 在浏览器里**用手机上绑定的同一个小米账号登录**
3. 登录成功后，页面会显示类似 `{"R":"","S":"OK"}` 的内容
4. **复制地址栏里 `unlock.update.miui.com` 开头的完整 URL**
5. 回到终端 **`Enter url:`** → 粘贴该 URL → 回车

> 工具会从 URL 里取 `userId` 和 `device` 完成鉴权。粘贴错域名会报 `Invalid URL`，重跑即可。

6. 接着会提示 `Press 'Enter' to continue`（区域确认）→ 直接回车
   （若识别区域不对，输入 `m` 手动选，**国区设备选中国**）

### C5. 阅读工具返回的信息

工具会调用小米服务器并打印：
- `product: alioth`
- `notice: ...`
- **`The device will clear user data when unlocked`** ← 你会看到这句（alioth 不免清数据）

然后它会尝试直接解锁。

### C6. 两种结果

**结果一：解锁成功** ✅
```
Unlock successful
```
（仅在已等满 168 小时的情况下）

**结果二：提示还需等待**（首次运行时几乎必然）
```
code: 10013
description: This device has been activated for less than 7 days, ...
```
→ **这是正常的**，记下提示的天数，等到期后再从 C1 重跑。

### C7. 解锁成功后

- 手机会**自动重启**并清空数据（首次开机很慢，耐心等 10~15 分钟）
- 开机后回到系统，重新走一遍开机向导
- 验证解锁状态：
  ```bash
  bash scripts/01-check-device.sh
  # 应显示: → 【BL 已解锁】可以进入 fastboot 刷入流程。
  ```
- **此时再重新登录小米账号、重开查找设备、重开 USB 调试**（数据清了，设置全丢）

## 阶段 D · 常见错误码速查

| Code | 含义 | 解决 |
|---|---|---|
| **10000** | token/产品无效 | 重启工具，更新到最新版 |
| **10013** | 设备激活不足 7 天 / 未激活 | 关自定义 DNS、SIM 换槽、关开查找设备、用移动数据开云同步；等提示的时间期满 |
| **20023 / 10023** | 该账号今年已解锁过设备 | **2025 年起一账号一年仅 1 台**；换账号或等一年 |
| **20030** | 本月已取过 token | 等下个月 1 号 |
| **20031** | 未在开发者选项绑定账号 | 回到 B4；若已绑定仍报错 → 在工具里手动选 `dataCenterZone` |
| **20033** | 账号被限制 | 开启「查找设备」；无效则换新账号 |
| **20035** | 解锁工具需升级 | 升级工具 |
| **20038** | 被账号通过「查找手机」锁定 | 登录 i.mi.com/mobile/find 关闭该设备的定位锁 |
| **20039** | 设备 token 不完整 | 暂无解法 |
| **20041** | 小米账号未绑手机号 | 去账号中心补绑手机号 |
| **20045** | 服务器区域 / 账号与设备区域不匹配 | 工具里改 `dataCenterZone`；国行设备用国区账号 |
| **30002** | 需去小米社区申请授权 | 仅 **HyperOS** 需此步；**你是 MIUI 13，不需要** |

## 阶段 E · 时间线示例

假设你 **今天（D0）** 完成 B4 绑定：

| 日期 | 动作 |
|---|---|
| D0 | 绑定账号设备，等待期开始 |
| D0~D7 | 正常用手机，**别退出账号/别恢复出厂**；固件在后台下载 |
| D7 同时刻后 | 手机关机 → fastboot → 跑 `miunlock` → 解锁成功、数据清空 |
| D7+ | 重新配置手机 → 刷入零售稳定版 → Magisk 打补丁 → 刷入 → root 完成 |
